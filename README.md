# Windows 11 ISO Bypass
A Python-based tool designed to bypass Windows 11 hardware requirement checks, including TPM 2.0, Secure Boot, and CPU compatibility during the installation process.

# ⚠️ Disclaimer
Use at your own risk.
This repository is provided for educational and administrative purposes. Bypassing system requirements may result in reduced system stability, lack of compatibility with certain features, and the potential for not receiving future security updates from Microsoft. Ensure you have backed up your data before modifying your installation process.

# Features

    TPM 2.0 Bypass: Disables the mandatory Trusted Platform Module check.

    Secure Boot Bypass: Allows installation on systems where Secure Boot is not enabled or supported.

    CPU Compatibility Bypass: Enables installation on processors not officially listed on the Microsoft-supported list.

    RAM/Storage Check Removal: Optional flags to ignore minimum RAM or disk size requirements.
